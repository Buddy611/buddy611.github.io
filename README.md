# buddy611.github.io

A simple placeholder page for my GitHub Pages user site.

It is shown at the main address and at every address that doesn't exist.
Project sites (for example `/schulplaner/`) are not affected.

## Files

- `index.html` – the start page
- `404.html` – the same page, shown by GitHub Pages for every unknown address

Everything is in one file with inline CSS. No external scripts, fonts or trackers.
Search engines are asked not to index the page (`noindex`).
